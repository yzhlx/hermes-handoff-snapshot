# Baseline

The authoritative UI 2.0 source is `outputs/`, recovered at commit `d8df4a9`. Product-source recovery identified `outputs/learning-os-ui-prototype.html` as the most complete preserved Canvas behavior reference.

At that baseline, the formal UI 2.0 root (`outputs/learning-os-app.html`) had no Canvas mount, no Canvas-model script inclusion, no workspace controller inclusion, and no formal navigation entry. Legacy handwriting tests targeted `learning-os-ui-prototype.html`.

The restoration preserves UI 2.0's HTML/CSS/JS/static architecture and uses its existing `learning-os-canvas-model.js`; it does not copy the prototype wholesale.
