# Learning OS MVP 产品设计

## 目标

将现有本地 Learning OS 原型扩展为单用户、本机优先的学习管理入口。MVP 覆盖今日安排、周计划、错题录入与分析、每日错题复习、AI 对话、学习状态记录和独立 AI 配置；不预置任何个人学习数据。

## 产品边界

- 本机优先：无需账号、不做自动云同步，电脑、平板和手机通过响应式页面使用同一台本地服务。
- 默认启用高等数学错题本，并每天安排 5 道滚动复习题。
- 信号是可创建、可单独启用的错题本，默认不强制显示。
- 其他学科、章节和错题本通过统一模型创建，不需要重做系统。
- 情绪、精力和压力仅生成非医疗的学习/休息建议，不做诊断或风险标签。

## 页面结构

桌面端采用固定主导航和主内容区；平板端侧栏可折叠；手机端改为顶部标题和底部主导航。

| 页面 | 用途 | MVP 内容 |
| --- | --- | --- |
| 今日 | 简洁执行台 | 当前任务、任务剩余时间、接下来两项、今日进度、今日错题复习、状态记录入口、建议 |
| 周计划 | 管理一周和每日任务 | 按日视图、任务新增/编辑、开始/暂停/完成/跳过/延期、优先级和完成进度 |
| 错题专栏 | 收集、编辑与分析错题 | 列表、筛选、上传/录入、分析详情、标签和复习历史 |
| 每日复习 | 完成高数滚动复习 | 今日 5 题、逐题回顾、复习结果、下次复习安排 |
| AI 对话 | 站内学习助手 | 新建/搜索对话、关联错题/任务/复习/状态、保存消息 |
| 学习记录 | 查看趋势与历史 | 按学科、章节、错误类型的错题统计；任务与状态历史 |
| 设置 | 控制本机与 AI | AI 配置、连接测试、数据导出、删除与隐私说明 |

首页只服务“现在该做什么”，不显示长期统计、完整错题列表或 API 配置。

## 核心工作流

### 错题录入与分析

错题允许录入原题文件或图片、作答过程、解题思路、正确答案、完整解析和可选备注。字段包括学科、章节、标签、错误类型、难度、复习次数、掌握状态和下次复习时间，均可后续编辑。

AI 分析可给出多个错误类型：概念/知识点、记忆、审题、思路、推理、计算、变形/符号、方法选择、盲目套公式、题型识别、粗心/注意力、时间管理和其他。每次分析必须给出主/次错误类型、错误步骤、引用证据、正确与错误思路差异、应掌握知识点、类似题检查法、30 字内建议、复习优先级和长期薄弱点建议。

材料不足时，分析结果标记为“信息不足”，明确缺失材料并提出最多 3 个问题，不生成武断分类。

### 每日复习

每日从高等数学错题本中选择 5 题。排序优先级依次考虑：长期未复习、高复习优先级、尚未掌握、最近再次出错。每题完成后可标记已掌握、部分掌握、仍不会、粗心导致错误或暂时跳过；系统记录历史并调整下次复习时间。

### 计划与今日执行台

周计划拆分为每日任务。任务拥有名称、学科、内容、预计用时、截止时间、优先级、状态、是否需要复习和备注。当前任务按计划时间判断；没有明确计划时间时，在当天未完成任务中按优先级和截止时间选择。计划偏离时给出重新安排建议，但不删除原计划。

### 状态记录

用户可记录心情、精力、压力、是否疲劳、是否愿意继续学习和备注，均为 1 至 5 级或布尔值。建议分为适合高强度学习、普通学习、复习/整理、短暂休息、较长休息和放松；连续学习过长、高压力或低精力时给出补水、走动、休息时长或降低任务难度等具体建议。

### AI 对话

站内对话可用于错题分析、知识点提问、计划调整、任务咨询、状态建议和复习记录。每个会话和消息本机保存并可搜索；消息可关联错题、任务、复习记录或状态记录。默认仅发送当前会话和主动关联的材料，不自动上传整个学习库。

## 数据模型与隐私

SQLite 保存学科/错题本、错题、错题分析、复习记录、周计划、任务、状态记录、AI 对话与消息。附件资产目录保存原题图片/PDF、答案解析、笔迹和导出包。每个实体拥有创建时间、更新时间和可删除状态。

API Key 不进入浏览器、SQLite、导出包或日志，使用 Windows 凭据管理器保存。设置页只显示提供商、端点、协议、模型、连接状态和掩码尾号。系统提供按对象删除、全库导出和全库清除；删除 AI 配置不会删除学习数据。

## AI 网关

AI 网关为可替换模块，支持 OpenAI Responses 和 OpenAI 兼容 Chat Completions 协议。每个提供商配置包含名称、端点、协议、模型、超时和凭据引用。网关负责连接测试、最小上下文组装、超时、可重试错误、响应格式验证和安全错误提示。

Gemini 的 DeepKey OpenAI 兼容 Chat Completions 配置作为已验证候选：模型为 `gemini-2.5-flash`，图片输入使用 `image_url`。凭据由设置页写入 Windows 凭据管理器后再由本地 API 读取。

## 实现架构

保留当前 Python 本地 API、SQLite 事件存储和手写画布，做渐进式模块化改造。前端拆分页面、共享组件、响应式样式和 API 客户端；后端拆分计划、错题、复习、状态、对话、AI 配置、文件和导出服务。现有 `127.0.0.1` 静态服务和 API 仍是本地启动入口。

## 失败处理与验证

- AI 失败时保留所有原始材料，可重试或人工补录；不暴露 Key 或上游响应体。
- 上传时校验文件类型、大小和解析结果，并在原位置提示原因。
- 信息不足分析和模型不可读的笔迹结果明确标记，保留人工编辑入口。
- API、规则、SQLite、浏览器交互和手机/平板响应式均有自动化测试。

## 交付物

项目完成后包含启动和构建命令、环境变量/凭据说明、数据存储与备份方案、AI 配置说明、部署说明、数据导出/删除说明及不含个人学习数据的示例数据。
