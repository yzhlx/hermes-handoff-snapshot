# 产品与交互规格

状态：待实现的新版规格；本文件不表示功能已经上线。适用产品：Hermes Learning OS，个人考研数字书房。运行方式：云端网站，同一账户在电脑和平板使用同一份学习数据。第一版须覆盖下列全部需求，可以分阶段开发，但不能以阶段完成替代第一版全范围验收。

## 1. 产品边界与需求编号

用户决定学什么，Hermes 帮助用户怎么学、恢复上下文、记录事实和看到真实变化。学习主要发生在教材、草稿纸、网课、真题和 PDF 中；网页提供辅助闭环。默认个人使用，不引入课程市场、社交竞争或学习指挥系统。

## 2. 信息架构与页面行为

主导航为“书房、学科、学习方法、学习记录、可考虑复习”。“我的金句、今日收尾、账户与数据设置”从轻量菜单进入。全局 AI 入口可放在导航或详情辅助区域，但学习进行页不主动显示。电脑可使用简洁侧边导航，平板使用收缩导航或抽屉，不能把桌面多列等比例缩小。

| 页面 | 主内容 | 关键操作 | 空状态与失败 |
|---|---|---|---|
| 书房首页 | 日期/金句、平等学科入口、继续上次、建议、方法、变化、复习 | 选择学科、自由开始、收藏/不喜欢、查看原因 | 新用户显示金句和学科/方法，无编造进步；单区失败显示重试，不拖垮全页 |
| 学科空间 | 章节、知识点、最近记录、卡点、错题、代表题、建议与变化 | 进入章节/知识点，选择学习内容 | 无记录提供“开始学习”；无章节可创建名称，不强迫预填完整课程树 |
| 知识点详情 | 最近现场、记录、问题、附件、五级状态及依据 | 学习、标代表题、主动修改参考状态、看证据 | 证据不足显示“暂无足够记录”；不能暗示未知即不掌握 |
| 学习方法 | 五方法、九情境选择 | 详情、开始使用、任选别的方法 | 推荐加载失败仍可浏览固定方法 |
| 学习进行 | 当前内容、可选用户目标、可选计时、结束 | 结束、恢复会话 | 刷新恢复运行会话；断网显示未同步，不能声称已经云端保存 |
| 结束反馈 | 本次学习事实；做题分题反馈；一句卡点；附件 | 保存草稿、保存反馈、稍后补答案 | 验证失败保留填写；可不强制写成果或卡点 |
| 题目详情/对比 | 题目材料、作答、核对、原因、卡点、历史尝试 | 补核对、追加尝试、标代表题、双例对比 | 附件失败独立重试；原题无文字仍能查看原材料 |
| 学习记录 | 日期/学科/知识点/错误原因筛选、事实统计 | 查看单条、继续、纠正记录 | 无记录不显示虚假趋势；修改后重新计算相关建议 |
| 可考虑复习 | 原因、证据、用户操作 | 选择任意项、开始、稍后、忽略 | 无建议显示“暂时没有”；无完成率目标 |
| 今日收尾 | 当日事实和依据 | 自愿查看、返回 | 当天无有效记录如实显示，不要求补打卡 |
| 我的金句 | 收藏列表 | 取消收藏、查看 | 不喜欢与收藏独立；收藏句即使被不喜欢仍可主动查看 |

## 3. 核心交互与状态机

### 3.1 云端共享与账户

同一身份登录电脑和平板后可见相同记录、附件、金句和建议处理状态。云端保存确认是跨设备可见的依据。未登录展示登录入口而不泄露私人记录；会话过期保留当前未提交内容，重新登录后继续。每用户进行中或暂停状态合计最多一个未结束会话；另一设备已有未结束学习时，提供继续该次或结束后新开，不静默启动重叠会话。跨设备同版本更新冲突返回409并提示刷新或选择保留版本，不静默覆盖。

以下账户、冲突、草稿机制是支持已确认云端使用的必要派生要求，编号为 UX-CLOUD，不冒充原 57 节内容。

### 3.2 学习会话

```text
未开始 → 进行中 ⇄ 暂停
进行中/暂停 --结束--> 已结束（待反馈）
已结束（待反馈） → 反馈草稿 → 已记录
已结束（待反馈） ─────────→ 已记录
进行中/暂停 --刷新/换设备--> 恢复同一未结束会话
待反馈/反馈草稿 --稍后处理--> 保持当前状态
```

开始只需用户动作，目标、学科、知识点、计时皆可空。选择内容或方法后保留来源，但用户可以改选。可选计时控件可暂停/继续；暂停仍属于未结束会话，不允许另一设备另开，暂停区间不计有效计时时长。进行中或暂停均可结束，结束动作冻结时间并进入反馈；重复点击结束不新增会话或重复计时。已记录是“事实已经保存”，不是“内容已经掌握”。待反馈也保留开始、结束与上下文，但不计作已完成题目。可直接保存简短学习事实，不能要求必须有题目。

非做题类反馈：实际做了什么、可选一句回忆/理解结果、可选卡点/下次位置。方法使用可记录回忆遗漏、执行差异、双例区别或自己的解释；都不要求完成固定量。题目记录可一次保存多题，每题独立反馈，共享会话上下文。

### 3.3 题目尝试与诚实反馈

```text
草稿 → 已保存未核对 → 已保存已核对
草稿 ────────────→ 已保存已核对
已保存（任一核对状态） --再次练习--> 新尝试，保留旧尝试
```

每题独立程度固定为“独立完成、有一些提示、看过答案以后完成、基本不会”。核对状态为“已经对过、暂时没有答案”。只有核对后才选“正确、部分正确、错误”；未核对的结果为空，不能用用户预估正确填充真实正确率。核对后可补结果/纠正事实，历史保留修订依据；再次做题是追加尝试而非覆盖第一次。

非完全正确可选择一个或多个原因：概念、思路/建模、条件判断、公式、推导、计算、符号/正负/方向、单位、审题、其他。原因可不确定、不填；未分类错误不能被 AI 静默分类为用户确认事实。“其他”可附一句说明。题目文本、题目附件、作答过程、答案材料和卡点允许分别补充；不要求复制整题。

代表题是题目属性，由用户标记/取消，与答对、掌握、已核对相互独立；大量标记时只给整理提示，不硬删旧题。掌握参考状态固定五级：陌生、接触过、典型题可完成、可以独立完成、变式比较稳定。无确认状态时显示“未设置”。用户可手动设定，系统可提出带证据的参考建议，由用户确认后改变状态；未核对、看答案完成不能自动升级。是否变式必须有用户注明的题型/条件变化证据，不能仅按正确次数推断。

### 3.4 建议、重复问题与双例对比

```text
可查看 → 已进入学习
      → 稍后（主动再次查看仍可）
      → 已忽略
```

进入学习是用户确认动作，不等于该建议已经解决。稍后默认隐藏7天，用户可改，仍可主动查看，不产生倒计时债务。忽略同一证据集合的建议后不重复弹出；只有新记录形成新证据时才允许生成新建议，并显示新依据。建议须存类型、主题、解释、证据记录、生成时间、处理状态；原证据失效或被修正后重新计算并撤回过时结论。

确定性建议可依据核对缺失、指定间隔、同知识点同错误原因重复等事实。复习初始间隔为7/14天，具体规则遵循学习规则规格；这些是待实测的可调初始参数，不是原需求承诺，也不宣传为保证科学最优；展示具体上次日期，绝不产生“逾期”。重复错误在同知识点最近20条已核对尝试中，同类错误至少3次才触发，提示实际次数和范围，不将无分类记录自动归类。相似题对比可由用户选择两题，或系统提出候选并注明相似依据；缺材料时不得断言两题相似。对比显示两题原材料，按七维填写差异；答案来自用户/材料与 AI 推断分开。跳过不改题目结果。

### 3.5 每日金句

按账户时区（默认 Asia/Shanghai）确定当天；服务器持久化日期与选句，不随刷新、设备、服务器重启改变。启用集合排除用户不喜欢的句子；每轮持久化随机顺序与游标，所有仍启用金句展示一次前不重复，下一轮重新洗牌。并发首次打开当天只能生成一次。

当天“不喜欢”立即隐藏当日金句，返回空展示，不自动替换另一句；持久化当日选择记录不变，次日起排除该句。若无可用句显示温和空状态，不能偷偷恢复屏蔽句。不喜欢与收藏独立；取消不喜欢可在偏好设置恢复，恢复的句子按已有轮内展示记录处理，已展示的不在同轮重复。全部不喜欢不阻断学习。跨午夜页面下次刷新/恢复前台更新日期，不回写昨日选择。完整保留原需求列出的 23 条首批金句；不得无授权替换为普通提醒或学习技巧。

### 3.6 附件

```text
已选择 → 上传中 → 上传完成待关联 → 已保存关联（可查看）
              → 上传失败 → 重试
```

图片/截图可预览；PDF 可选择页码，保存原 PDF 与页码引用并查看该页；原题文件保存名称、类型、大小与下载入口，不能伪装所有格式均支持在线预览。上传成功且题目关联成功后才能显示“已保存”。附件上传中可继续填写但不把未完成附件算成功；失败保留反馈和待上传信息。刷新后本机未上传文件需重新选择，明确提示。附件保存不依赖 OCR、AI 或全 PDF 识别成功；这三项不是附件保存的前提。

### 3.7 AI 与故障降级

AI 帮助整理事实、解释变化、给方法建议，不能代替用户对答案或判掌握。输出分“记录事实、可能解释、缺失材料、可选方法”，附可打开的证据。没有数据时不生成“连续进步”；缺尝试过程时指出无法定位具体步骤。失败、超时、无法识图、材料不全时说明真实状态，保留原文/附件，可重试且不重复创建记录。基础记录、固定方法、金句、用户主动学习在 AI 不可用时仍能工作。AI 文案渲染前验证数据引用与权限，展示引用失效状态，不显示其他账户材料。

## 4. 方法内容与情境映射

五方法详情严格保持“问题—适用—步骤—误区—开始使用”，以短操作为主，不强制理论阅读或作业量。

| 当前情境 | 默认可尝试方法 | 应解释的原因 |
|---|---|---|
| 刚听完课，感觉听懂 | 主动回忆、费曼式检查 | 检查能否离开原话复述 |
| 一看题不知道下手 | 实际执行与反馈 | 先留下尝试，定位入口缺失 |
| 看答案会，自己不会 | 实际执行与反馈、主动回忆 | 区分看懂与独立完成 |
| 两道题很像但做法不同 | 双例对比 | 比较条件与入口 |
| 公式很多容易混 | 主动回忆、双例对比 | 比较适用条件和公式差异 |
| 以前学过现在忘了 | 间隔复习、主动回忆 | 重新提取而非假装从未忘记 |
| 同类问题反复错 | 实际执行与反馈、双例对比 | 回看真实尝试和差异 |
| 状态差只想开始一下 | 低阻力主动回忆或自由学习 | 可只做一次尝试，不设达标量 |
| 知道要干什么 | 自由学习 | 直接开始，不强插方法 |

推荐方法始终可改选；方法不会决定某学科必学。间隔复习提供选择材料、合上材料尝试回忆、核查、记下遗漏、以后自愿回来五步。双例对比保留七维但允许只填写真正相关维度。费曼式检查支持自己的简短文字或线下自述后的记录，不要求录音。

## 5. 事实指标、收尾与视觉

“独立正确”仅统计独立完成且已核对且正确的尝试。连续正确按同知识点有效核对尝试的实际时间排序，不跨入其他知识点；提示原始次数和时间范围。多原因统计表示“涉及此原因的题目尝试数”，同一尝试同原因只计一次，各原因合计可超过总题数并说明原因。删除/修正/补核对后重算，未知不当零，空分母显示暂无记录，不产生 NaN 或虚假百分比。

有效学习记录为已保存且含实际学习内容或已提交题目反馈的会话；仅打开网站、运行计时但未记录实际内容不算。近七天是账户时区包含今天的七个自然日；学习会话创建时冻结开始时区与开始日为学习归属日期，跨日结束或晚到反馈不改变归属，不能用浏览器时间任意漂移。收尾只统计归属当天的真实记录，未核对题单列“待补核对”，不能计入正确题。学习时长可选辅助显示，不替代问题解决和事实变化。

视觉采用暖米色书房、深墨文本、克制留白、低饱和辅助色，统一样式变量和系统字体。七区不是七个等重的大卡片；每日金句和学科选择最醒目，变化与建议次之。无霓虹、巨大 AI 球、重阴影、数据驾驶舱。噜噜可安静出现，可隐藏并尊重减少动态偏好，不遮挡按钮，不作为通知权限管理员。

必须检查 1440×900、1366×768、1024×768、768×1024、390×844：导航可用、无横向溢出、表单/附件可见、键盘焦点、触控目标至少 44px、对比在窄屏可上下排列、屏幕阅读器标签、可关闭对话框、减少动态、对比度。长期阅读正文保持舒适行宽；平板软键盘出现时保存按钮与主要输入可到达。
