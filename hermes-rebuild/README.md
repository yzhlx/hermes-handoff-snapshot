## 快速运行

环境：Node24、pnpm11.19.0、Python3.12+、uv。前后端各自安装、构建和运行，首次运行需要下载依赖。

在本目录执行：

```sh
pnpm install --frozen-lockfile
pnpm --dir apps/web install --frozen-lockfile
uv sync --project apps/api --frozen
pnpm contracts:check
```

进入apps/api，显式迁移并创建本地账号：

```sh
uv run python -m hermes_api.cli migrate
uv run python -m hermes_api.cli bootstrap --username YOUR_USERNAME
uv run uvicorn hermes_api.main:app --host 127.0.0.1 --port 8000
```

bootstrap会安全提示密码，也可通过HERMES_BOOTSTRAP_PASSWORD环境变量提供，至少12字符。不会覆盖已有账号。默认本地数据库为apps/api/hermes-development.db，仅用于演示；测试使用独立临时数据库。请勿在生产环境使用演示配置。

附件校验和预览需要另开终端，在apps/api执行`uv run --frozen python -m hermes_api.attachment_worker --poll-seconds 2`。API和worker必须使用相同的数据库与`HERMES_ATTACHMENT_LOCAL_ROOT`（开发默认apps/api/.local/attachments）；自定义配置见apps/api/.env.example。生产强制配置私有S3对象存储，不能以开发目录代替。

另开终端在本目录执行`pnpm dev:web`，打开[本地数字书房](http://127.0.0.1:5173)。首页展示服务端固定的每日金句，收藏与不喜欢独立保存；学习现场不展示金句。可选择学科或自由学习，可选计时，暂停/恢复/结束/取消并刷新恢复；学习方法页支持五种方法和九种情境，记录页显示真实会话。结束后或历史详情中可保存学习反馈、继续位置和文字题目，并分别保存追加作答或更正记录；未核对作答不计正确证据。章节、知识点、版本化掌握依据以及私有附件已接入；完整产品仍按需求矩阵推进。前端开发代理转发/api到独立API端口8000。

章节、知识点、题目关联、用户自评与可追溯证据已实现，实测见17；私有图片/PDF原件、指定页安全预览及题目附件关联已实现，实测见19；确定性复习建议、接受/稍后/忽略、按日期学科记录和事实收尾已接入，实测见21；其余完整产品范围继续按10推进。

七区书房已接入真实金句、五学科、继续学习、学习线索、方法、近七日变化和可回顾建议。结束现场的继续入口只预填目标，确认开始后保存前序关联；噜噜可隐藏并恢复。各区失败可独立重试，跨日期重读整页；本批测试、五视口和数据库重启验证见[书房首页交付](23-书房首页交付.md)。

运行检查：

```sh

uv run --project apps/api --frozen ruff check apps/api/src apps/api/tests
```

## 本地PostgreSQL组合部署

Docker可用时，复制infra/.env.example到infra/.env并替换随机密码，执行：

```sh
docker compose --env-file infra/.env -f infra/compose.yaml up -d postgres
docker compose --env-file infra/.env -f infra/compose.yaml build
docker compose --env-file infra/.env -f infra/compose.yaml run --rm api python -m hermes_api.cli migrate
docker compose --env-file infra/.env -f infra/compose.yaml run --rm api python -m hermes_api.cli bootstrap --username YOUR_USERNAME
docker compose --env-file infra/.env -f infra/compose.yaml up -d api attachment-worker web
```

入口http://127.0.0.1:8085；数据库和API不直接映射公网。此compose是HTTP本地集成配置，Docker构建/运行验证状态见09。生产需TLS、安全cookie、备份恢复、限速、告警及实际PostgreSQL集成测试。
