# 知识组织与用户自评证据增量计划

状态：本批实现前的边界与迁移决策，不是验收结果。完整产品目标仍以01/06/10为准。已执行基线：API90项、前端43项通过，API有1条既有Starlette/httpx警告。

## 产品边界

落实FR-003/007/024/025/033及相关真实证据基础：平等学科入口、上海大学829归属、章节/知识点组织、按知识点开始学习、题目知识点关联、用户五级自评与可追溯尝试证据。未知显示未设置；没有记录不生成进步；计时、看答案和未核对不升级掌握。

本批不将独立卡点、附件/PDF、复习建议、双例对比、收尾节奏、噜噜和AI当成已实现；这些仍必须在完整目标中继续完成。

## 数据与迁移

- 0005：chapters、knowledge_points、problem_knowledge_links；learning_sessions增量knowledge_point_id，旧记录为null。章节/知识点保留owner、版本、时间及可恢复归档；知识点保存chapter_id和由章节确定的subject_id，联合外键强制同账号、同学科关系。会话选择知识点时必须有匹配学科，服务端可从知识点推导缺省subject_id。
- 0006依赖0005：mastery_assessments和mastery_evidence_links。每次自评创建新的不可覆盖声明，保留五级历史、理由和可选变式说明；关联保存作答与题目版本快照，不写自动掌握结论。
- 自评提交使用知识点If-Match版本作为并发门禁，成功同事务增加知识点版本并新建声明。自评记录本身创建version1，不修改旧声明；响应带新的knowledge_point_version。原题或作答修订使旧证据stale，不自动改变用户原等级。
- 所有私有引用有数据库归属联合外键；新建、更新和关联在账号锁、幂等、权限和事务内。无生产数据库迁移，不修改旧项目或导入旧数据。
- 用已有0004账号、会话/计时、题目、作答和金句偏好升级；验证ID、内容、版本、时间和归属保持，新列null，revision到0006且foreign_key_check为空。先做临时库恢复验证；真实生产迁移前必须另行备份、实测恢复和明确授权。隔离库downgrade会删除本批组织/自评数据，不是无损生产回退。

## 接口与响应边界

沿用/api/v1、Envelope、统一ErrorEnvelope；读鉴权，写另需Origin/CSRF及Idempotency-Key=operation_id。所有可变资源更新要求If-Match，缺省428，过期409附current_version及本人当前快照；不属于本人统一404；空输入/非法关联422；存储故障503。生成OpenAPI为实际形状唯一来源。

| 接口 | 关键行为 |
| --- | --- |
| GET /subjects | 保留原items并增加可选group_label，默认信号/电路为上海大学829，其余公共课；自由学习不创建第六科 |
| GET /subjects/{id}/space | 本人学科信息、实际章节页、最近会话与题目摘要；不返回未实现建议等伪造成功区块 |
| POST /chapters、GET /chapters、GET /chapters/{id}、PATCH /chapters/{id} | 创建名称、按subject分页/归档筛选、详情、修改名称/顺序/归档恢复；不跨学科移动 |
| POST /knowledge-points、GET /knowledge-points、GET /knowledge-points/{id}、PATCH /knowledge-points/{id} | 章节归属、名称、notes、分页/归档筛选、详情、修改和恢复；不跨章节移动 |
| PUT /problems/{id}/knowledge-links | operation_id、knowledge_point_ids[]；以题目版本整体替换关联；重复ID拒绝、可空解绑，题目版本递增；已有指定学科时不得关联其他学科 |
| POST /learning-sessions | 增加可选knowledge_point_id，验证本人有效知识点与学科匹配；保留kind/previous_session_id；旧调用继续合法 |
| GET /knowledge-points/{id}/evidence | 真实统计、来源ID/版本、规则版本、自评历史和动态evidence_status；空数据为零计数与null比例，不伪造变化 |
| POST /mastery-assessments | operation_id、knowledge_point_id、level、reason?、variant_note?、evidence_attempt_ids[]；If-Match为知识点版本；创建声明及来源版本快照 |

章节/知识点名trim后1–200字符；notes最多20000，reason/variant_note最多2000；列表默认20、最多100，以(created_at,id)稳定分页。归档不级联抹去历史。父章节归档使子知识点不可新开学习，但不改子自身归档标记；恢复父后保留原子状态。历史会话仍可恢复/查询。

## 证据规则

自评level=unfamiliar/encountered/typical/independent/variant_stable。用户可无证据声明任一级，返回unsupported和“自评，暂无已核证据”。关联作答须本人、已核对、所属题目当前关联该知识点；independent/variant_stable的关联证据须独立正确，variant_stable关联时另需用户明确variant_note。用户的变式说明是用户记录，不能宣传为系统客观验证。

读取时比较保存来源的作答/题目版本、当前知识点关联及核对资格；发生变化为stale，仍保留原自评。实时派生指标不需要复制一套永久真相：去重尝试数、待核对数、已核对数、已核对正确比例、独立正确数、十类已确认错误涉及的尝试数，以及最近已核对独立正确序列。提示/看答案/错误均打断该序列；另有待核对时明确指出，不能宣称全部连续正确。全部指标返回来源，可查原记录；一个题目多个知识点在同一范围内不重复计数。
